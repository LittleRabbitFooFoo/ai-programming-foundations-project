    Rework decode_categorical_codes to use pd.merge instead of dict-mapping.
    
    Previously built a Python dict from the lookup subset and applied it
    with .astype(str).map(code_to_label) -- workable, but an unnecessary
    detour when pandas already has a direct tool for "join a lookup table
    onto a dataframe by key": merge. Now each field's lookup rows
    (code/format, label) are pulled from the data guide, renamed to
    {field, field_label}, and merged onto df on that field (left join,
    string keys on both sides for the same category-dtype-from-CSV reason
    as before). The temporary {field}_label column replaces the original
    coded column and is dropped.
    
    Also carried over the user's manual phrasing edits made directly in
    the notebook (2021-2025 inclusive; underscore-style italics; a couple
    of trimmed sentences; a note on the data guide's historical mapping
    sheet) -- those were already on disk and are untouched here.
